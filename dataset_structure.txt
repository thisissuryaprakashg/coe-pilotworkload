PhysioNet: Multimodal Physiological Monitoring During Virtual Reality Piloting Tasks
CogPilot Data Challenge (Version 1.0.0)

1. OVERVIEW
-----------
This dataset contains synchronized multimodal physiological, flight performance, and 
pilot control streams collected from 35 human participants performing simulated 
Instrument Landing System (ILS) flight tasks of four varying difficulty levels in 
virtual reality (VR), along with resting-state baseline periods.

- Total Participants: 35 de-identified subjects (sub-cp003 to sub-cp043)
- Experimental Session Duration: ~4 hours per participant (12 ILS runs + 2 rest runs)
- Virtual Environment: X-Plane 11 (v11.50) + HTC Vive Pro Eye VR Headset
- Aircraft Model: T-6 Texan II turboprop trainer
- Flight Controls: Thrustmaster HOTAS Warthog (flight stick, dual throttle, rudder pedals)
- Data Synchronization Engine: Lab Streaming Layer (LSL v113)

3. FILE NAMING CONVENTION
-------------------------
Files follow BIDS-inspired standardized naming conventions:

Format:
  sub-<SubjectID>_ses-<Date>_task-<Task>_stream-<StreamName>_feat-<FeatureType>_level-<Level>_run-<RunID>_<dat|hea>.csv

Components:
  - sub-cpXXX       : Subject de-identified identifier (e.g., sub-cp003)
  - ses-YYYYMMDD    : Session acquisition date (e.g., ses-20210206)
  - task-XXXX       : Task type: 'ils' (flight trials) or 'rest' (baseline rest)
  - stream-XXXX     : Data stream identifier (e.g., lslshimmerecg, lslhtcviveeye)
  - feat-XXXX       : Feature payload ('chunk' = raw time series, 'perfmetric' = flight error)
  - level-XXX       : Experimental difficulty level:
                      * level-000 : Resting baseline
                      * level-01B : Difficulty 1 (No wind/turbulence, clear visibility)
                      * level-02B : Difficulty 2 (Overcast 2500', vis 5 mi, 10 kt wind)
                      * level-03B : Difficulty 3 (Overcast 1000', vis 3 mi, light turb)
                      * level-04B : Difficulty 4 (Overcast 400', vis 1 mi, turb, wind gusts)
  - run-XXX         : Chronological run number (run-001 to run-012 for ILS; run-001 to run-002 for rest)
  - _dat.csv        : Comma-separated numerical sensor sample measurements
  - _hea.csv        : Sensor stream metadata header (nominal Fs, effective Fs, sample count)


4. SENSOR STREAMS & DATA CHANNELS
---------------------------------

A. Electrocardiography (ECG)
   - Stream Name: stream-lslshimmerecg
   - Hardware: Shimmer3 ECG Unit (Chest-mounted)
   - Nominal Fs: 512 Hz (Effective ~504 Hz)
   - Columns:
     1. time_dn                  : MATLAB datenum timestamp
     2. ecg_projection_ll_ra_mV  : Lead II / Left Leg - Right Arm potential (mV)
     3. ecg_projection_la_ra_mV  : Lead I / Left Arm - Right Arm potential (mV)
     4. ecg_projection_vx_rl_mV  : Chest / Precordial Lead potential (mV)

B. Electrodermal Activity (EDA) & Photoplethysmography (PPG)
   - Stream Name: stream-lslshimmereda
   - Hardware: Shimmer3 GSR+ Unit (Left hand fingers & palm)
   - Nominal Fs: 1024 Hz (Effective ~128 Hz)
   - Columns:
     1. time_dn                  : MATLAB datenum timestamp
     2. ppg_finger_mV            : Photoplethysmogram pulse signal (mV)
     3. eda_hand_l_kOhms         : Skin impedance / conductance level (kOhms)

C. Electromyography (EMG) & Forearm Accelerometry
   - Stream Name: stream-lslshimmeremg
   - Hardware: Shimmer3 EMG Unit (Right forearm)
   - Nominal Fs: 512 Hz (Effective ~504 Hz)
   - Columns:
     1. time_dn                          : MATLAB datenum timestamp
     2. accelerometry_forearm_r_x_mps2   : Forearm X acceleration (m/s^2)
     3. accelerometry_forearm_r_y_mps2   : Forearm Y acceleration (m/s^2)
     4. accelerometry_forearm_r_z_mps2   : Forearm Z acceleration (m/s^2)
     5. emg_wrist_flexor_mV              : Wrist flexor muscle activation (mV)
     6. emg_wrist_extensor_mV            : Wrist extensor muscle activation (mV)

D. Respiration
   - Stream Name: stream-lslshimmerresp
   - Hardware: Respitrace / Shimmer Respiratory Inductance Plethysmography (Chest band)
   - Nominal Fs: 512 Hz (Effective ~504 Hz)
   - Columns:
     1. time_dn                  : MATLAB datenum timestamp
     2. respiration_trace_mV     : Chest expansion waveform voltage (mV)

E. Eye Tracking & Pupillometry
   - Stream Name: stream-lslhtcviveeye
   - Hardware: HTC Vive Pro Eye VR Headset
   - Nominal Fs: 250 Hz (Effective ~90-120 Hz depending on VR render pipeline)
   - Columns:
     1. time_dn                      : MATLAB datenum timestamp
     2. validity_l, validity_r       : Binary gaze tracking validity flags (0/1)
     3. gaze_origin_l_[x,y,z]_mm     : Left eye 3D gaze origin in VR space (mm)
     4. gaze_origin_r_[x,y,z]_mm     : Right eye 3D gaze origin in VR space (mm)
     5. gaze_direction_l_[x,y,z]     : Left eye normalized unit gaze vector
     6. gaze_direction_r_[x,y,z]     : Right eye normalized unit gaze vector
     7. pupil_diameter_l_mm          : Left pupil optical diameter (mm)
     8. pupil_diameter_r_mm          : Right pupil optical diameter (mm)
     9. eye_openness_l, eye_openness_r: Normalized eye openness factor [0.0 = closed, 1.0 = fully open]
     10. pupil_position_l/r_[x,y,z]  : Pupil center coordinate in sensor frame
     11. convergence_distance_mm     : 3D binocular gaze convergence distance (mm)
     12. convergence_distance_validity: Validity flag for convergence distance

F. Aircraft State & Flight Dynamics
   - Stream Name: stream-lslxp11xpcac
   - Source: X-Plane 11 simulation output via LSL connector
   - Nominal Fs: 4-20 Hz
   - Columns:
     1. time_dn                      : MATLAB datenum timestamp
     2. aircraft_velocity_[e,u,n]_mps: Aircraft east/up/north velocity components (m/s)
     3. aircraft_elevation_trim      : Pitch elevator trim setting
     4. aircraft_aileron_trim        : Roll aileron trim setting
     5. aircraft_latitude_deg        : Geodetic latitude (degrees)
     6. aircraft_longitude_deg       : Geodetic longitude (degrees)
     7. aircraft_elevation_m         : Elevation above sea level (meters)
     8. aircraft_agl_altitude_m      : Above Ground Level altitude (meters)
     9. aircraft_pitch_deg           : Aircraft pitch angle (degrees)
     10. aircraft_roll_deg           : Aircraft roll angle (degrees)
     11. aircraft_yaw_deg            : Aircraft heading/yaw angle (degrees)
     12. aircraft_indicated_airspeed_kias: Indicated airspeed (knots)
     13. aircraft_groundspeed_mps    : Ground speed (m/s)
     14. aircraft_climb_rate_mps     : Vertical speed / rate of climb (m/s)
     15. aircraft_ils_deflection_gs  : Glide slope instrument needle deflection
     16. aircraft_ils_deflection_h   : Localizer horizontal needle deflection
     17. aircraft_landing_gear       : Landing gear deployment state

G. Pilot Interaction & Head Tracking
   - Stream Name: stream-lslxp11xpcplt
   - Source: X-Plane 11 cockpit head position & control captures
   - Columns:
     1. time_dn                          : MATLAB datenum timestamp
     2. pilot_head_position_[f,h,v]_m    : Forward/Horizontal/Vertical head position (m)
     3. pilot_head_[roll,pitch,yaw]_deg  : 3-DOF head orientation angles (degrees)

H. Flight Performance Error Metrics
   - Stream Name: stream-lslxp11_feat-perfmetric (Per-run time-series) & PerfMetrics.csv (Summary)
   - Columns in Time-Series (*_feat-perfmetric_*.csv):
     1. time_dn                  : MATLAB datenum timestamp
     2. glideslope_error_deg     : Angular deviation from ideal 3-deg descent glide slope (capped at [-3, 3] deg)
     3. localizer_error_deg      : Angular deviation from runway centerline localizer (capped at [-3, 3] deg)
     4. airspeed_error_kts       : Scaled deviation from ideal 115 kts (|v - 115| / 10, capped at [-3, 3])
     5. total_error              : Instantaneous sum = |e_GS| + |e_LOC| + |e_IAS|
   - Columns in Summary (PerfMetrics.csv):
     1. subject, date, run, difficulty
     2. cumulative_glideslope_error_deg
     3. cumulative_localizer_error_deg
     4. cumulative_airspeed_error_kts
     5. cumulative_total_error


5. EXPERIMENTAL DIFFICULTY PROTOCOL
-----------------------------------
Difficulty 1 (Low Workload / Baseline Task):
  - Wind: None
  - Clouds: None (Unlimited visibility)
  - Turbulence: None

Difficulty 2 (Moderate-Low Workload):
  - Wind: 140° @ 10 kts
  - Clouds: Overcast above 2,500 ft
  - Visibility: 5 statute miles
  - Turbulence: None

Difficulty 3 (Moderate-High Workload):
  - Wind: 3,000 ft: 80° @ 10 kts | 1,000 ft: 140° @ 10 kts
  - Clouds: Overcast above 1,000 ft
  - Visibility: 3 statute miles
  - Turbulence: Light turbulence above 1,000 ft

Difficulty 4 (High Workload / Stress):
  - Wind: 4,800 ft: 250° @ 10 kts | 2,800 ft: 80° @ 15-20 kts | 800 ft: 200° @ 15 kts
  - Clouds: Overcast above 400 ft
  - Visibility: 1 statute mile
  - Turbulence: Light turbulence throughout descent


6. TIME SYNCHRONIZATION & TIMESTAMP CONVERSION
----------------------------------------------
All streams are timestamped using MATLAB datenum (`time_dn`), representing the fractional 
days since January 0, 0000.
To convert `time_dn` to UNIX epoch milliseconds:
  t_millis = (time_dn - 719529) * 86400 * 1000
where 719529 is the MATLAB datenum offset corresponding to 1970-01-01 00:00:00 UTC.
LSL guarantees sub-millisecond inter-stream clock synchronization across the heterogeneous sensors.
