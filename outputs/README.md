# Outputs

This folder contains generated data products from the pipeline.

- `new_master_features.csv` - primary windowed feature matrix.
- `enhanced_features.csv` - normalized and temporally enhanced features.
- `signature_features.csv` - eye and pupil signature features.
- `tda_features.csv` - topological features.
- `covs_*.npy` and `covs_*_meta.csv` - covariance features and metadata.
- `covariances.npy` and `cov_meta.csv` - existing covariance artifacts.

These files are outputs, not source inputs. Scripts should be run from the repository root using the documented module commands. Existing artifacts are preserved when organizing the project; they are not regenerated by this cleanup.
